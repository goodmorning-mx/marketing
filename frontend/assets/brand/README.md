# Official platform marks

These logo image files come from Meta's Brand Resource Center. Each file is used at its original colors and proportions; Facebook's supplied image is cropped only to remove surrounding blank canvas.

- [Meta Brand Resource Center](https://www.meta.com/brand/resources/)
- [Facebook logo guidance](https://www.meta.com/brand/resources/facebook/logo/)
- [Instagram brand assets](https://www.meta.com/brand/resources/instagram/instagram-brand/)
