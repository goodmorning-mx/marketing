# Social platform image assets

These locally stored assets are used only by the public landing page. Legacy shared brand files remain unchanged for dashboard routes. The supplied source files are retained where practical; updated landing-page assets are listed below.

- `facebook.png` — official 2084 × 2084 transparent primary logo from the [Meta Facebook Brand Resource Center](https://www.meta.com/brand/resources/facebook/logo/) logo pack.
- `instagram-gradient.png` — official 5000 × 5000 transparent gradient glyph export from the [Meta Instagram Brand Resource Center](https://www.meta.com/brand/resources/instagram/instagram-brand/) logo pack. The pack's SVG wrapper embeds a raster image, so this high-resolution PNG is used directly.
- `whatsapp.svg` — official 2026 digital RGB green glyph from the [Meta WhatsApp Brand Resource Center](https://www.meta.com/brand/resources/whatsapp/whatsapp-brand/).
- `linkedin.svg` — official blue [LinkedIn [in] logo](https://brand.linkedin.com/in-logo), kept as vector artwork so its transparent letterforms render white on the solid light surface used by the site.
- `x-logo.svg` — official white X mark from the [X Brand Toolkit](https://about.x.com/en/who-we-are/brand-toolkit), stored as vector artwork for the dark landing-page backgrounds.
- `tiktok-transparent.png` — official multicolor mark from TikTok's [developer logo pack](https://sf16-va.tiktokcdn.com/obj/eden-va2/uvzhqeh7nuhd/tt4d/logo-pack.zip), linked from the [TikTok design guidelines](https://developers.tiktok.com/docs/en/getting-started-design-guidelines).
- `youtube-cropped.png` — official red play-button artwork from YouTube's [official icon pack](https://www.gstatic.com/marketing-cms/78/29/3e68a1414bb28d0b7e47b44c3c91/youtube-icon.zip), available from [YouTube Brand Resources](https://brand.youtube/youtube-icon).
- `meta-wordmark.svg` — official transparent negative primary symbol-and-wordmark lockup from the [Meta company brand resources](https://www.meta.com/brand/resources/meta/company-brand/).
- `meta-symbol.svg` — dashboard-sized symbol extracted from the official `meta-wordmark.svg` artwork above; used for the Meta channel icon.

The earlier `instagram.png` and `whatsapp.png` exports and the legacy `facebook.jpg` and `meta-wordmark.jpg` files are retained; the public landing page now uses the locally stored files named above. TikTok and YouTube use crisp high-resolution transparent exports because their official packs provide standalone raster symbols rather than standalone symbol SVGs.
