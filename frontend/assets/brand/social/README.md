# Social platform image assets

These high-resolution image marks are used by the public landing page. The HTML keeps existing dashboard references to the older shared files unchanged.

- `instagram.png` — 272 × 272 PNG from the [Meta Brand Resource Center](https://www.meta.com/brand/resources/instagram/instagram-brand/).
- `whatsapp.png` — 1600 × 1600 PNG from the [Meta Brand Resource Center](https://www.meta.com/brand/resources/whatsapp/whatsapp-brand/).
- `linkedin.png` — 240 × 220 PNG, 2× [LinkedIn [in] Logo download](https://brand.linkedin.com/in-logo).

Other public landing-page marks retain their existing sources: Facebook from the [Meta Brand Resource Center](https://www.meta.com/brand/resources/facebook/logo/), and TikTok and YouTube as scalable SVGs from [Simple Icons](https://github.com/simple-icons/simple-icons).
